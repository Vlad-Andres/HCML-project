# Human-Centered Machine Learning Project

We analyzes the Open University Learning Analytics Dataset (OULAD) to evaluate fairness and explainability across demographic and different subgroups.

## How to run

Create and activate a Python environment

  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

Now you can run the notebook and it will install all the needed packages in the first cell

## Dataset

The dataset contains these tables:

- `courses.csv`
- `assessments.csv`
- `studentAssessment.csv`
- `studentInfo.csv`
- `studentRegistration.csv`
- `studentVle.csv`
- `vle.csv`

### Feature categories

We generate features families in the following way:

- Course context
  - `code_module`
  - `code_presentation`
  - `module_presentation_length`
- Demographic
  - `gender`
  - `age_band`
  - `highest_education`
  - `imd_band`
  - `region`
- VLE engagement
  - `vle_total_clicks`
  - `vle_active_days`
  - `vle_mean_clicks_per_record`
  - `vle_max_clicks_per_record`
  - `vle_num_records`
  - `vle_clicks_per_active_day`
  - `clicks_<activity_type>`
- Assessment behavior
  - `assess_num_submitted`
  - `assess_mean_score`
  - `assess_min_score`
  - `assess_max_score`
  - `assess_weighted_score_sum`
  - `assess_total_weight_seen`
  - `assess_late_rate`
  - `assess_mean_days_before_due`
- Registration / other
  - `date_registration`
  - `registered_before_start`
  - `days_registered_before_start`
  - `num_of_prev_attempts`
  - `studied_credits`

## Models

> We train 3 calssifiers to compare their biases and fairness.

- Logistic Regression 
- Random Forest 
- XGBoost 

## Explainability Methods

### SHAP feature importance

We genereate local and global SHAP values
- `src/explainability.py` computes SHAP values for tree models

### Subgroup SHAP analysis

> We use subgroup analysis constructing groups by sensitive attributes : `highest_education` and `imd_band`

### Additional explainability methods

- Permutation Feature Importance (PFI) 
- Partial Dependence Plots (PDP) 

### Feature family importance

> SHAP values are generated by feature family
- `VLE engagement`, `Assessment`, `Demographic`, `Course context`, and `Registration / other`

## Project Structure

- `src/config.py` — configuration constants, dataset keys, and required file names
- `src/data_loader.py` — data loading and OULAD file resolution helpers
- `src/feature_engineering.py` — target creation, VLE/assessment aggregation, registration features, and stage dataset construction
- `src/modeling.py` — preprocessing, train/test splitting, model building, training, and evaluation
- `src/explainability.py` — SHAP analysis and feature family importance
- `src/fairness.py` — subgroup fairness metrics and gap summaries
